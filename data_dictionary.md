# Data Dictionary

| Field | Description |
|---|---|
| Age | Patient age |
| Gender | Recorded gender |
| Blood_Type | Blood group |
| Medical_Condition | Primary medical condition |
| Date_of_Admission | Admission date |
| Hospital | Hospital name |
| Insurance_Provider | Insurance provider |
| Billing_Amount | Recorded billing amount |
| Room_Number | Assigned room |
| Admission_Type | Emergency, Urgent or Elective |
| Discharge_Date | Discharge date |
| Medication | Recorded medication |
| Test_Results | Normal, Abnormal or Inconclusive |
| Length_of_Stay | Days between admission and discharge |
